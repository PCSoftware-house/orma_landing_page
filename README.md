# Orma — Landing Page & Interactive Demo

> Il sistema operativo di nuova generazione per la gestione della ristorazione (HoReCa).

Questo repository contiene il codice sorgente della landing page e dell'anteprima interattiva di **Orma**, visibile su [orma.com](https://orma.com).

## 🛠️ Stack Tecnologico

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + Lucide React (Icons)
- **Design System:** Dark Satin Minimalist (`#0B0B0C`)

## 🚀 Sviluppo Locale

```bash
# Installa le dipendenze
npm install

# Avvia il server di sviluppo
npm run dev

# Compila la build per la produzione
npm run build
```

Copia `.env.example` in `.env` se servono variabili locali. Il file `.env` non va versionato.
